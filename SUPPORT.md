# Support

How to get help with Aura Code.

## Bug reports and feature requests

Open a [GitHub issue](https://github.com/DusanCar-sudo/aura-code/issues).
Use the issue templates so the report has the details needed to reproduce —
Aura Code version, OS, model/provider, and what you expected versus what
happened.

## Questions and usage help

- Read the [website](https://www.leanproiq.com) and the
  [Aura Code manual](https://dusancar-sudo.github.io/aura-website/) for setup,
  providers and the CLI workflow.
- For anything else, open a GitHub issue labeled `question` — there is no
  separate discussion forum yet.

## Security issues

Do **not** open a public issue for security vulnerabilities. Follow
[docs/SECURITY.md](docs/SECURITY.md) and report privately.

## Response expectations

Aura Code is maintained by a single maintainer, so responses are best-effort.
Issues with a clear reproduction and the version info from the templates get
looked at first.
