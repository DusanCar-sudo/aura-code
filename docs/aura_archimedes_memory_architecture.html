Commission :designx Engine

Routes 2–3 opinionated style directions (e.g. Swiss Overdriven + Risograph) from a hand-curated lexicon. Pre-flights web search references, builds self-contained single-file artefacts (web/deck/pdf), and writes DESIGN.md.

Principle Archimedes Alternation

A small local model (IBM Granite 4.1 3B / Qwen 1.5B via Ollama) handles repetitive tasks in a read-only sandbox. A large cloud model steps in only when historical competence is low or answer verification fails.

Zero-Tool Gate Claim-Aware Verification

Archimedes's answers are verified with one cheap, zero-tool complete() call. Retrieval tasks strictly check tool evidence to eliminate hallucinations; design tasks allow novel proposals while keeping factual premises strict.

Event-Sourced 4-Layer Sleep Memory

Experience is recorded as immutable episodes (L1), periodically consolidated into daily dreams (L2), statistically reconciled into a projection with mechanical confidence (L3), and injected into the prompt (L4). No model feelings.
