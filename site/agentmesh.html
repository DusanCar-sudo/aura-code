Local agents, strict contracts, shared memory.

AgentMesh is a Python multi-agent harness for programming work. It decomposes a goal, dispatches bounded tasks to specialist agents, checks hard completion conditions, and stores raw run history for future routing.

What changed

Stop asking one giant agent to behave. Give each job a contract.

AgentMesh treats agents like bounded workers, not a single sprawling prompt. The orchestrator decomposes a goal into two to four concrete tasks, each with its own agent, allowed tools, token budget, output path, and required JSON keys.

The result is easier to inspect: every subtask leaves a contract, a result, and a memory trace. Failures become data for the next run instead of vanishing into a transcript.

PlanBreak one goal into narrow contracts.
DispatchRun independent groups in parallel.
GateCheck required keys and hard completion rules.
LearnPersist episodes, lessons, and skill effectiveness.

Runtime board

A terminal cockpit for autonomous work.

Memory system

The harness keeps the raw run, not just the story.

AgentMesh stores episodes, extracted lessons, and skill statistics in SQLite. The next plan can use prior outcomes, Honcho context when configured, and provider history from the server learner.

Install

Clone it, install it, hand it a goal.

AgentMesh supports direct source usage through `run.py` and package entrypoints from `pyproject.toml`: `agentmesh`, `agentmesh-server`, `agentmesh-lean`, and `agentmesh-mcp`.

1

Install Python dependencies. The project requires Python 3.10 or newer.

2

Choose a provider key. `run.py` supports DeepSeek, Groq, OpenRouter, Anthropic, Gemini, and Together.

3

Run a goal. Add `--stream`, `--status`, `--test`, `--provider`, or `--model` as needed.

quickstart.sh 
$ git clone https://github.com/DusanCar-sudo/agentmesh.git
$ cd agentmesh
$ python -m pip install -e .
$ export DEEPSEEK_API_KEY=...
$ python run.py --stream "Research this repo and write a test plan"
$ python run.py --status
