Help for Aura Code, the Aura plugins for VS Code and Zed, and Aura adOS. The fastest route is a GitHub issue: it is public, so the next person with the same problem finds the answer too.

Open an issue on GitHub

Before you write

Two quick checks solve most problems.

aura --version     # which version you have
node --version     # Aura needs Node 18 or newer

If Aura is behind, update it with npm install -g aura-code and try again.

Common questions

Aura says there is no API key.
Aura works with the model provider you choose, and you bring your own key. Add it in Aura’s setup. Keys stay on your machine, in your own key store, and are never sent to us.
The editor plugin cannot find Aura.
The plugin drives the aura command. Install Aura first, then reload the editor so it sees the command on your PATH.
Will Aura change my files without asking?
It asks before it runs commands or edits files, unless you have turned that off yourself.
What leaves my computer?
Your prompts, and the file content Aura needs to answer them, go to the model provider you picked, under their terms. Nothing is sent to us. Voice features send audio to the voice provider you configure.

What to put in a bug report

  • Your Aura version, your operating system and your editor, if the plugin is involved.
  • What you did, what you expected, and what happened instead.
  • Any error text, copied as text. Remove API keys and passwords first.

Security problems

If you found a vulnerability, please do not post it publicly. Follow the private reporting steps in SECURITY.md.
